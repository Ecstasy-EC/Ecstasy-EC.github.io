{% comment %} Reusable media block for publications and featured entries. Renders one of: 1. youtube = YouTube video ID (the 11 characters after `?v=`) A click-to-load facade: thumbnail plus play button. Nothing is requested from YouTube until the visitor clicks, which keeps pages fast and keeps Google's tracking off them. The swap-in is handled by the small script in _includes/scripts.html. With JavaScript disabled the facade stays a plain link to youtube.com, so it degrades rather than breaks. 2. image = a still, normally Figure 1 of the paper Letterboxed into the same 16:9 frame the videos use, so rows line up. Path is relative to /images/ ("figures/top.jpg"), or an absolute URL. `youtube` wins if both are given.
